# Converted C0–C7 incident packs

Generated by `python3 scripts/convert_benchmarks_to_packs.py` from:

- **Cyber-SecOps-ES** investigation questions → `secops/`
- **Cyber-AIT-ADS** attack-stage windows → `ait_ads/`

`manifest.json` lists every pack path, source scenario, and event count.

Each file is a valid incident pack (`alert`, `telemetry` with `event_id`s,
`oracle_evidence`, `oracle_plan`, `fixed_query_pack`, sealed `ground_truth`).

Regenerate after refreshing benchmark downloads:

```bash
python3 scripts/download_benchmarks.py
python3 scripts/convert_benchmarks_to_packs.py
```
